# [Pastebin.md](https://kibikalo.github.io/pastebin-md/)

Your lightweight Markdown workspace in the browser. [Try it here](https://kibikalo.github.io/pastebin-md/)

Pastebin.md
 is a **minimal, standalone Markdown editor** for the web. A simple space where you can quickly paste, write, and format Markdown with live preview.

*No accounts, no setup — just open and start writing.*

## Features
    - Live Preview with synchronous scrolling
    - Toolbar & Keyboard Shortcuts for quick formatting
    - Code Syntax Highlighting with Highlight.js
    - Dark/Light Theme Switcher for comfortable editing
    - Responsive Design for desktop & mobile

## Tech Stack
    - React.js
    - Tailwind CSS (Typography plugin)
    - Marked.js
    - Highlight.js
